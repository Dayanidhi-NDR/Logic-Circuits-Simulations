# Logic Circuits Simulation
This repository contains simulations of fundamental digital logic circuit simulations created as part of Digital Electronics & VLSI learning.

## Contents
- Basic Logic Gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- Combinational Circuits
  - Half Adder
  - Full Adder
  - Multiplexer & Demultiplexer
  - Encoder & Decoder
- Truth Tables 

## Tools Used
- CircuitVerse

## Purpose
- Understand digital logic design concepts.
- Practice circuit simulation and verification.
- Build a strong foundation for VLSI and Embedded Systems.

## Output
- Simulation screenshots
- Truth table
- Result
