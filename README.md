# Logic Circuits Simulation
This repository contains simulations of fundamental and advanced digital logic circuits created as part of Digital Electronics / VLSI learning.

## Contents
- Basic Logic Gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- Combinational Circuits
  - Half Adder
  - Full Adder
  - Multiplexer & Demultiplexer
  - Encoder & Decoder
- Sequential Circuits
  - SR, JK, D, T Flip-Flops
  - Counters
  - Registers
- Truth Tables and Timing Analysis

## Tools Used
- CircuitVerse

## Purpose
- Understand digital logic design concepts
- Practice circuit simulation and verification
- Build a strong foundation for VLSI and Embedded Systems

## Output
- Circuit diagrams
- Simulation screenshots
- Logic verification results
